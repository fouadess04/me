## Flagship Systems & Embedded Light-Mode UIs

The portfolio embeds interactive light-mode interfaces directly inside a cosmic `Space Mono` dark shell so visitors can test real product workflows in the browser:

### 01 // BClass — The AI Operating System for Higher Education
- **Live Platform:** [bigoviclass.com](https://bigoviclass.com)
- **Traction (University of Blida 1):** `655+` registered students (`80–90%+` cohort saturation), `30.5%` DAU/MAU stickiness, `18,841+` curated questions (`246` past exams, `181` BNotes), `954.1+` verified study hours, `>96%` unit gross margin (`0 DZD` CAC).
- **Embedded Astro Light UI:**
  - **Courses (`CourseMockup`):** Live 6-course marquee, dynamic course theme shifting, and interactive `Cours` / `Quiz` progress checklists.
  - **BNote Reader (`BNoteShowcase`):** Textbook-grade study guide with `BQS 96/100` scoring, substance/hormone highlights, `5px` focus callout cards, and slide-up `BClass-AI` token streaming.
  - **B-AI Quiz (`QuizShowcase`):** Official past exam simulation (`Blida 2024`) with interactive QCM selection, slide-page citations, and streaming AI explanations.
- **Stack:** Django · React & React Native · Astro · Gemini Multimodal OCR/LLM · PostgreSQL · OVHcloud · Cloudflare R2

### 02 // SANAD — National Emergency Tele-Expertise & Case-Routing Engine
- **Mission:** Connecting generalist doctors in rural or under-equipped hospitals with named on-call specialists at reference CHUs within a guaranteed, server-authoritative SLA timeframe.
- **Embedded Clinical Light UI:**
  - **File de Garde:** Live 1-second server SLA countdown rings, priority filtering (`Critique`, `Urgent`, `Courant`), and zero-pool named dispatch.
  - **Dossier & Avis:** Structured emergency case viewer (`12-lead ECG`, vitals, rural EPH context) and specialist clinical orientation sign-off.
  - **Preuve SHA-256:** Append-only, SHA-256 hash-chained clinical audit registry (`case_events`) with daily UTC Merkle roots.
- **Stack:** TypeScript · PostgreSQL 16 (Append-Only Registry) · React 19 · React Native · Redis & BullMQ

### 03 // TABIB Desktop (طبيب) — Offline-First Medical Practice OS
- **Mission:** Commercial offline-first desktop application for Algerian medical cabinets (`1 doctor + 1 assistant`) with 100% local SQLite data sovereignty and hardware-bound licensing.
- **Embedded Desktop Light UI:**
  - **Salle d'Attente:** Live triage status filter (`URGENT`, `EN ATTENTE`, `ROUTINE`) and patient waiting queue synced over LAN with the Assistant web interface.
  - **Ordonnance A5:** Interactive Algerian drug nomenclature (`meds-dz`) with live bilingual FR/AR A5 prescription preview and isolated print spooling.
  - **Licence Ed25519:** Hardware-fingerprinted (`TBB-XXXX-XXXX-XXXX`) asymmetric WebCrypto Ed25519 + AES-GCM concierge activation engine.
- **Stack:** Tauri 2 · Rust · React 19 · TypeScript · SQLite · Zustand · WebCrypto Ed25519 / AES-GCM · Tailwind v4
